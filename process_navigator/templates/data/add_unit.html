Add Unit

Welcome to the Add Unit page. Here we can add a new unit.

Each unit is composed of a number of unit parts. Each unit part is composed of a base unit, a unit modifier, and an exponent. The base unit is the fundamental unit of the unit part. The unit modifier is a prefix or suffix that modifies the base unit. The exponent is the power to which the unit part is raised. e.g Km2 is a unit part with a base unit of m, a unit modifier of K, and an exponent of 2.

We can then compound this unit part with other unit parts to create a unit. e.g. Km2 + s-1 = Km2s-1
